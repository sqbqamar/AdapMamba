# AdapMamba-UNet

Code for **"Hierarchical Gated Mamba Network for Multi-Scale Medical Image Segmentation"**.

AdapMamba-UNet is a 2D encoder-decoder segmentation network built on a VMamba-Small
encoder. Three decoder-side modules are added:

| Module | Role |
|---|---|
| **PAU**, Progressive Adaptive Upsampling | CARAFE content-aware 2x reassembly followed by channel and spatial recalibration |
| **HCAG**, Hierarchical Channel-spatial Attention Gate | conditional channel-spatial gating of encoder skip features (no query-key-value attention) |
| **APFA**, Adaptive Pyramid Feature Aggregation | fusion of all four decoder stages through dilated depth-wise separable branches weighted by global, learnable softmax coefficients |

This repository contains everything needed to regenerate every number in the paper:
training, evaluation, statistics, cost measurements, ablations and the tables themselves.

---

## Installation

```bash
git clone https://github.com/sqbqamar/AdapMamba.git && cd AdapMamba
pip install -r requirements.txt
pip install mamba-ssm          # fused selective-scan CUDA kernel, required for GPU training
bash scripts/download_pretrained.sh
```

Tested with Python 3.10 to 3.12 and PyTorch 2.1 or later. Without `mamba-ssm` the code runs a
pure-PyTorch reference selective scan; it is exact but far too slow for training and is intended
for CPU tests.

## Data

Raw data are preprocessed into a common format (`volumes/*.h5` with voxel spacing, and
`slices/*.npz`):

```bash
# Synapse / BTCV: RawData/Training/{img,label}/*.nii.gz
python preprocess.py synapse --raw RawData/Training --out data/synapse
# ACDC: database/training/patientXXX/
python preprocess.py acdc --raw ACDC/database/training --out data/acdc
```

* **Synapse**: HU clipped to [-125, 275] and rescaled to [0, 1]; BTCV labels mapped to the eight
  organs of the standard protocol. Splits in `splits/synapse_*.txt`: the TransUNet 18/12
  train/test partition, with cases 0021, 0030 and 0037 held out of training for checkpoint selection.
* **ACDC**: both annotated frames (end-diastole, end-systole) per patient, each volume
  z-score normalised, all slices kept. Splits in `splits/acdc_*.txt`: a 70/10/20 patient split
  stratified by diagnostic group, generated by `scripts/make_acdc_split.py` (seed 2026).

Dataset sources: Synapse <https://www.synapse.org/Synapse:syn3193805>,
ACDC <https://www.creatis.insa-lyon.fr/Challenge/acdc/>.

## Reproducing the paper

| Paper item | Command |
|---|---|
| Synapse main result (3 seeds, per-seed + ensemble) | `bash scripts/reproduce_synapse.sh data/synapse` |
| ACDC main result | `bash scripts/reproduce_acdc.sh data/acdc` |
| ACDC loss-weight grid search | `bash scripts/grid_search_acdc.sh data/acdc` |
| All ablation tables (stepwise, factorial, upsampling, gate, APFA) | `bash scripts/run_ablations.sh data/synapse` |
| Parameters, FLOPs, latency, memory, resolution scaling | `bash scripts/profile_all.sh` |
| Significance tests and per-organ Holm correction | `python stats.py --a results/synapse/full/ensemble_cases.csv --b <baseline>/ensemble_cases.csv --out results/synapse/stats` |
| Model-generated tables and the per-seed data file | `python make_tables.py --results results --cost results/cost_224.csv` |

Each ablation row corresponds to a named configuration in `adapmamba/configs.py`;
`python train.py --config <name>` trains it.

### Outputs

* `runs/<dataset>/<config>/seed<k>/`: `best.pth` (highest validation DSC), `last.pth`, `log.csv`
  (per-epoch loss, learning rate and validation DSC) and `run_config.json` (arguments, model
  configuration, pretrained-loading report, data split, software versions, git commit).
* `results/<dataset>/<config>/`: per-case metrics for each seed (`seed_<k>_cases.csv`), for the
  seed-averaged ensemble (`ensemble_cases.csv`), and `summary.json` with mean and sample
  standard deviation across seeds.
* `results/tables/seed_results.csv`: every metric for every configuration and seed.

## Protocol details

* **Training**: AdamW (β = 0.9, 0.999; ε = 1e-8; weight decay 1e-2, with the SSM parameters
  A and D excluded as in VMamba), gradient clipping at 1.0, FP32. Synapse: 300 epochs, batch 24,
  learning rate 3e-4 with cosine annealing, 224 x 224. ACDC: 200 epochs, batch 32, OneCycleLR with a
  peak learning rate of 1e-4 (reached after 30% of training), 256 x 256. Seeds 42, 123, 256;
  deterministic cuDNN settings.
* **Initialisation**: encoder from ImageNet-1K VMamba-Small (v0 checkpoint, stage depths
  [2, 2, 27, 2]); AdapMamba-UNet uses depths [2, 2, 3, 2], so stages 1, 2 and 4 are loaded in full
  and stage 3 uses the first three pretrained blocks. All other convolution and linear layers use
  Kaiming-normal initialisation; SSM-specific parameters keep the standard Mamba initialisation.
* **Evaluation**: slices are predicted independently and stacked into volumes; all metrics are
  volumetric. For ACDC the end-diastolic and end-systolic results of each patient are averaged,
  so each patient is one case.
* **HD95** is reported in two forms. `hd95mm` uses the voxel spacing and treats HD95 as undefined
  (excluded and counted) when a prediction or ground truth is empty. `hd95tu` reproduces the
  TransUNet evaluation rule (voxel units, empty prediction scored 0), which produced most published
  Synapse baselines. State which one is reported.
* **Statistics**: the unit is the test case. Methods are compared on per-case DSC of their
  seed-averaged softmax predictions, with Shapiro-Wilk, paired t-test, Wilcoxon signed-rank,
  Cohen's d for paired data, a 95% t-interval, and Holm-Bonferroni correction across classes.
* **Determinism**: the fused selective-scan kernel uses atomic additions in its backward pass, so
  repeated GPU runs with the same seed agree to within floating-point noise rather than bitwise.

## Changelog

* **v1.0**: complete implementation used for the revised manuscript. It replaces the preliminary
  upload of February 2026, whose SS2D was a convolutional approximation without a selective scan,
  which did not load pretrained weights, and whose Synapse and ACDC evaluation protocols differed
  from the paper.

## Reproducibility metadata added in this consistency revision

Training `run_config.json` now records the release version, the exact pretrained-checkpoint SHA256,
the runtime PyTorch/CUDA/cuDNN versions, GPU, and the git commit when run from a Git clone
(or `ADAPMAMBA_RELEASE_COMMIT` when supplied by an archived release environment).
ACDC OneCycleLR explicitly sets `pct_start=0.3`.

Literature-only comparison rows in the paper are not regenerated by this repository; only
model-generated, ablation, profiling, and statistical outputs are regenerated.
